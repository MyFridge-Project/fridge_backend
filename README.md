## Описание
`fridge_backend` — это набор микросервисов, которые обеспечивают основную логику работы системы:
- Управление холодильниками и продуктами.
- Аутентификацию пользователей.
- Маршрутизацию запросов.
- Интеграцию с Telegram-ботом и внешними API.

---

## Микросервисы

### 1. **API Gateway**
- **Функции**:
  - Маршрутизация запросов от пользователя между микросервисами.
  - Проверка JWT-токена.
  - Отправка ответа обратно пользователю.
- **Локация**: `api_gateway/`
- **Зависимости**:
  - PostgreSQL (для хранения JWT-токенов).
  - Redis (для кэширования).

### 2. **Fridge Service**
- **Функции**:
  - Добавление/удаление холодильников.
  - Управление продуктами (добавление, удаление, обновление).
  - Листинг продуктов.
- **Локация**: `fridge_service/`
- **Зависимости**:
  - PostgreSQL (хранение данных о продуктах и холодильниках).
  - Kafka (для отправки событий о добавлении/удалении продуктов).

### 3. **User Service**
- **Функции**:
  - Хранение данных пользователей.
  - Генерация JWT-токенов.
  - Создание/удаление пользователей.
- **Локация**: `user_service/`
- **Зависимости**:
  - MySQL (хранение пользователей).
  - Redis (кэширование токенов).

---

## Технологии
- **Язык**: Go (Golang).
- **База данных**: MySQL.
- **Кэширование**: Redis.
- **Событийная система**: Apache Kafka.
- **Структура**: Монорепозиторий с модульной архитектурой.
